# Heiden intro — prompts for the Higgsfield web app

Use these on higgsfield.ai with plan credits (or hand this file to Claude in Chrome in a desktop chat).

**Settings for every clip:** 16:9, 4 or 5 seconds, 720p is enough (1080p if credits allow), audio OFF. Model: Seedance 2.5 with the reference image attached (so the bike looks the same in every shot). Kling 3.0 Pro image-to-video is the fallback for shots 01 to 04, using the reference image as the first frame.

Save each result as the filename given, put it in `heiden-video/clips/`, then run `./build.sh`.

## Step 1 — reference image (SOUL or any image model, 16:9, 1080p)


Pick the cleanest result and attach it as the image reference for every video below.
